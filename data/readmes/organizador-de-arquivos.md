# 📁 Organizador de Arquivos em Python

Script desenvolvido para automatizar a organização de arquivos em pastas por tipo (imagens, documentos, vídeos, etc).

## 🚀 Funcionalidades
- Organização automática de arquivos por categoria
- Criação de pastas automaticamente
- Tratamento de arquivos duplicados (evita sobrescrever)
- Geração de log das operações realizadas

## 🛠️ Tecnologias utilizadas
- Python
- Bibliotecas: os, shutil

## ▶️ Como executar
1. Defina o caminho da pasta no código
2. Execute o script:
   python organizador.py

## 📌 Objetivo
Projeto desenvolvido com foco em automação de tarefas e aplicação prática de lógica de programação, simulando cenários reais de otimização de processos (RPA).
