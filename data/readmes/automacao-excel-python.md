# 📊 Automação de Excel com Python

Script para análise automatizada de dados de vendas em Excel.

## 🚀 Funcionalidades
- Leitura de planilhas Excel
- Cálculo de total de vendas
- Agrupamento por cliente
- Identificação do produto mais vendido
- Geração automática de relatório

## 🛠️ Tecnologias
- Python
- Pandas
- OpenPyXL

## 📌 Objetivo
Simular automação de processos de negócio, com foco em análise de dados e geração de relatórios.
